Transférer ma licence

Chaque code QR est lié à 1 appareil. Vous pouvez le transférer librement dans une fenêtre de 1 an.

📋 Conditions du transfert

  • Votre licence doit avoir moins de 1 an depuis son activation initiale
  • Chaque licence peut être transférée sur un nouvel appareil
  • L'ancien appareil perdra l'accès après le transfert
  • Les licences école : le transfert est géré par l'enseignant via l'app prof

🔄 Procédure — Transfert automatique

  1. Installez le jeu sur votre nouvel appareil
  2. Allez dans Réglages → Activer un code de licence
  3. Entrez votre même code QR (XXXX-XXXX-XXXX)
  4. Le jeu détecte que le code est sur un autre appareil et propose le transfert
  5. Confirmez — l'activation est transférée automatiquement

⚠ Transfert refusé ?

Le transfert peut être refusé si :

  • La licence a plus de 1 an depuis l'activation initiale
  • Un transfert a déjà été effectué récemment sur ce code

Dans ce cas, écrivez à coresrdi@outlook.com avec votre code et votre situation. Nous traiterons votre demande manuellement.
