📱 Transférer sa licence

Nouveau téléphone, nouvelle tablette ? Voici comment réactiver Mathéquête.

👤 Licence individuelle

Une licence individuelle est liée à un appareil à la fois. Pour l’activer sur un nouvel appareil, deux cas de figure :

Cas 1 — Changement normal (6 mois écoulés)

  1. Installe Mathéquête sur ton nouvel appareil.
  2. Au premier lancement, choisis J’ai déjà une licence.
  3. Saisis ton code de licence (reçu par courriel lors de l’achat).
  4. Si 6 mois ou plus se sont écoulés depuis ta dernière activation, le transfert est automatique et instantané.

Cas 2 — Transfert urgent (moins de 6 mois)

Si tu dois changer d’appareil avant les 6 mois (téléphone perdu, brisé, vol), écris-nous :

  1. Envoie un courriel à coresrdi@gmail.com avec l’objet « Transfert urgent licence Mathéquête ».
  2. Inclus ton code de licence et une brève description de la situation.
  3. Nous traitons les demandes urgentes dans les 24 h ouvrables.

🏫 Licence école (enseignant·e)

Pour les licences école, c’est l’enseignant·e qui gère les transferts depuis le tableau de bord prof. Aucun contact avec le support n’est nécessaire.

Procédure — Tableau de bord prof

  1. Ouvre l’application Tableau de bord sur ton ordinateur Windows.
  2. Va dans Ma classe → Liste des élèves.
  3. Clique sur l’élève concerné, puis sur Révoquer la licence.
  4. Le code QR de cet élève devient immédiatement réutilisable sur un autre appareil.
  5. Donne le même code QR à l’élève pour qu’il l’active sur son nouvel appareil.

⚠️ Un code QR révoqué ne fonctionne plus sur l’ancien appareil. L’élève doit activer le nouveau appareil avant de pouvoir jouer.

Informations complémentaires

Mon ancien appareil est encore fonctionnel. Que se passe-t-il dessus ?

Dès que le transfert est validé, la licence est désactivée sur l’ancien appareil. Mathéquête passe en mode non-activé (Continent 1 jouable en démo gratuite, sans progression sauvegardie).

Ma progression est-elle conservée après le transfert ?

La progression est sauvegardée localement sur l’appareil. Lors d’un changement d’appareil, la progression du nouvel appareil commence à zéro. La synchronisation cloud de la progression est une fonctionnalité prévue pour une version future.

Je n’ai plus mon code de licence original.

Recherche dans tes courriels l’objet « Votre licence Mathéquête ». Si tu ne le retrouves pas, écris-nous à coresrdi@gmail.com avec l’adresse courriel utilisée lors de l’achat.

J’ai acheté sur Google Play. La procédure est-elle différente ?

Non. Le système de licence Mathéquête est indépendant de Google Play. Tu utilises ton code QR Crockford (reçu par courriel) de la même façon, quelle que soit la plateforme.
