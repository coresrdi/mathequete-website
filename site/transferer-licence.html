Transférer une licence

Changer d’appareil sans perdre votre accès.

D’abord : quel type de licence avez-vous ?

Les règles de transfert dépendent de l’endroit où vous avez acheté.

🌐

Achetée sur mathequete.ca

Vous avez reçu un courriel avec un code d’activation (format MQ-CONT-XXXX) après votre achat.

  • ✅ Activable sur tout appareil compatible (Android, Windows)
  • ✅ Licence permanente : transférable une seule fois par période de 12 mois
  • ❌ Licence annuelle : non transférable (liée à l’appareil d’activation pour la durée de l’abonnement)
📧 Pour initier un transfert : coresrdi@gmail.com avec votre code MQ-CONT-XXXX.
🐍

Achetée via Google Play

Vous avez acheté directement dans l’application Android depuis le Play Store.

  • ✅ Liée à votre compte Google
  • ✅ Accessible sur tout appareil Android connecté avec le même compte Google — aucune manipulation requise
  • ❌ Non transférable vers un autre compte Google
  • ❌ Non utilisable sur Windows (Android seulement)
💡 Pour changer d’appareil Android, connectez-vous simplement avec le même compte Google et relancez l’app. Aucun code à saisir.

Étapes d’un transfert (licence Stripe permanente)

Achetée sur mathequete.ca seulement — licences permanentes uniquement.

Vérifiez l’éligibilité

Votre licence doit être de type permanent (Solo permanent ou Pack 5 permanent). Le transfert n’est permis qu’une seule fois par période de 12 mois par licence.

Contactez le support

Envoyez un courriel à coresrdi@gmail.com avec votre code de licence (MQ-CONT-XXXX), le modèle de l’ancien appareil, et le modèle du nouvel appareil.

Confirmation

Notre équipe révoque la licence sur l’ancien appareil et émet un nouveau code d’activation. Délai habituel : 24 à 48 heures ouvrables.

Activation

Entrez le nouveau code dans l’application Mathéquête sur votre nouvel appareil. La progression repart de zéro (sauvegarde locale non transférable entre appareils).

Licences école

L’enseignant·e gère les transferts depuis le tableau de bord prof.

  1. Ouvrez l’application Tableau de bord sur votre ordinateur Windows.
  2. Allez dans Ma classe → Liste des élèves.
  3. Cliquez sur l’élève concerné, puis sur Révoquer la licence.
  4. Le code QR de cet élève est immédiatement réutilisable sur un autre appareil.

⚠️ Un code QR révoqué cesse de fonctionner sur l’ancien appareil dès la révocation.
