Prochaines étapes

1. Vérifie tes courriels Ton code arrive dans 1 à 2 minutes à l'adresse utilisée au paiement. Pense à vérifier ton dossier spam ou courrier indésirable si tu ne le vois pas tout de suite.
2. Télécharge Mathéquête
Android (bientôt sur Google Play) Steam (à venir)

En attendant la publication officielle, le lien APK direct est inclus dans ton courriel de confirmation.

3. Active ton code dans le jeu Ouvre Mathéquête → Réglages → Licence → saisis ton code. Une seule connexion internet est nécessaire pour activer ; ensuite, le jeu fonctionne hors-ligne.

📚 Tu es enseignant·e ? Si tu as acheté une licence école, tu recevras un PDF contenant un code par élève ainsi qu'un code prof. Voir le guide école pour la distribution.
