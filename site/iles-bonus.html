Créer une île bonus

Compose tes propres questions et obtiens un fichier .mqpack.json à importer dans Mathéquête. Idéal pour les enseignants qui veulent personnaliser un thème, ou pour les parents qui préparent un défi sur mesure.

4. Comment l'importer dans le jeu

  1. Transfère le fichier .mqpack.json sur l'appareil où Mathéquête est installé (clé USB, courriel, partage en ligne, etc.).
  2. Ouvre Mathéquête → Carte du Continent → menu Îles bonus.
  3. Choisis Importer un pack et sélectionne le fichier .mqpack.json.
  4. L'île apparaît dans le continent choisi. Maximum 6 îles bonus par continent — si le slot est plein, le jeu propose de remplacer une île existante.
