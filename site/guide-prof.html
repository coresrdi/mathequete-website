Activation pas-à-pas

De l'achat à la première épreuve, en 5 étapes.

Achetez en ligne

Choisissez votre palier sur la page d'achat. Paiement sécurisé par Stripe avec facture automatique.

Recevez le PDF

Dans les minutes qui suivent, vous recevez un courriel avec un PDF contenant un code par élève + un code prof.

Distribuez les codes

Un code par appareil élève (tablette, portable, téléphone). Les codes restent personnels à chaque élève.

Activez dans le jeu

Sur chaque appareil : Mathéquête → Réglages → Licence → saisir le code. Une seule connexion internet requise.

Consultez les stats

Avec votre code prof, accédez au tableau de bord de classe (disponible Sprint F — vous serez avisé·e dès la sortie).
