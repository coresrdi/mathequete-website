Centre d'aide

Une question ? Consultez les rubriques ci-dessous ou écrivez-nous directement.

🔑

Activer mon code

Ouvrez le jeu → Réglages → Gérer mes licences (activer / transférer) → saisissez votre code XXXX-XXXX-XXXX. Une connexion Internet est requise pour l'activation initiale.

📱

Changer d'appareil

Votre licence est transférable dans une fenêtre de 1 an. Allez dans Réglages → Gérer mes licences (activer / transférer), puis activez votre code sur le nouvel appareil. Un seul transfert est autorisé par licence.

📴

Jeu hors-ligne

Après l'activation initiale, le jeu fonctionne sans Internet pendant 40 jours. Après 40 jours sans connexion, le jeu revient en mode gratuit jusqu'à la prochaine synchronisation.

👨‍👩‍👧

Plusieurs profils

Une licence active sur un appareil débloque le contenu pour tous les profils de cet appareil. Pas besoin d'acheter plusieurs fois pour la même tablette familiale.

🏫

Licences école

Pour les établissements scolaires, consultez le Guide école. Pour un devis ou une aide à la distribution, écrivez à coresrdi@gmail.com.

🪟

Windows PC

Disponible sur le Microsoft Store et en téléchargement direct sur la page Applications. Le tutoriel est gratuit. Pour débloquer le contenu, allez dans Réglages → Gérer mes licences (activer / transférer) ou utilisez la section Licence prof / promo / essai si vous avez un code promotionnel.

🤖

Android

Disponible sur Google Play. Recherchez MathéQuête. Le tutoriel et la première île sont gratuits. L'achat du Continent 1 (7 îles complètes débloquées d'un coup) peut se faire directement sur notre site pour nous encourager, ou via Google Play dans l'application.

🐛

Signaler un bug
