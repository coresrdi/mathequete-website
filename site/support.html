Centre d’aide

Une question ? Consultez les rubriques ci-dessous ou écrivez-nous directement.

🔑

Activer mon code

Ouvrez le jeu → Réglages → Gérer mes licences (activer / transférer) → saisissez votre code MQ-CONT-XXXX. Une connexion Internet est requise pour l’activation initiale.

📱

Changer d’appareil

Les licences permanentes sont transférables une seule fois dans les 12 premiers mois suivant l’activation. Après un transfert, la licence n’est plus transférable, même si la fenêtre de 12 mois n’est pas écoulée. Les licences annuelles ne sont pas transférables.

→ Guide complet du transfert

📴

Jeu hors-ligne

Une connexion internet est requise une seule fois tous les 40 jours pour valider votre licence. Entre ces validations, le jeu fonctionne entièrement hors ligne.

👨‍👩‍👧

Plusieurs profils

Une licence active sur un appareil débloque le contenu pour tous les profils de cet appareil. Pas besoin d’acheter plusieurs fois pour la même tablette familiale.

🏫

Licences école

Pour les établissements scolaires, consultez le Guide école. Pour un devis ou une aide à la distribution, écrivez à coresrdi@gmail.com.

🪟

Windows PC

Téléchargement gratuit via le Microsoft Store ou en direct sur la page Applications. Le tutoriel est gratuit. Pour débloquer le contenu, achetez votre licence sur mathequete.ca, puis entrez votre code dans Réglages.

ℹ️ L’achat intégré n’est pas disponible dans le Microsoft Store.

🤖

Android

Disponible sur Google Play. Recherchez MathéQuête. Le tutoriel et la première île sont gratuits. L’achat du Continent 1 peut se faire via Google Play (flux natif) ou sur mathequete.ca. Attention : une licence achetée sur mathequete.ca n’est pas utilisable sur un autre OS.

🐛

Signaler un bug

Décrivez le problème par courriel en incluant : plateforme, version du jeu (visible dans Réglages), description du problème et capture d’écran si possible.

🍏

iOS

La version iOS est en développement. Inscrivez-vous à notre liste d’attente pour être informé à sa sortie. Aucune date n’est confirmée pour l’instant.
