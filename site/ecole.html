Questions fréquentes

Comment distribuer les codes aux élèves ?

Après le paiement, vous recevez un PDF contenant un code QR scannable par élève. L’élève l’active directement dans Mathéquête en allant dans Réglages → Licence → Scanner un code QR. Le guide complet est disponible sur la page Guide école.

La licence couvre-t-elle toute l’année scolaire ?

Oui. Les licences école sont valides 12 mois à compter de la date d’achat. Elles peuvent être renouvelées chaque année scolaire au même tarif. Un rappel de renouvellement vous est envoyé 30 jours avant expiration.

Un élève change d’appareil en cours d’année. Que faire ?

L’enseignant peut révoquer et réattribuer un code QR depuis le tableau de bord prof. L’opération prend quelques secondes et ne nécessite pas de contacter le support.

L’application tableau de bord est-elle incluse ?

Oui, elle est entièrement gratuite pour tous les enseignants, que ce soit avec une licence école ou individuelle. Téléchargement disponible sur la page Enseignants.

Mon école n’a pas de carte de crédit. Peut-on payer par bon de commande ?

Oui. Écrivez-nous à coresrdi@gmail.com avec le nom de votre établissement et le forfait souhaité. Nous pouvons émettre une facture formelle compatible avec les processus d’approbation des commissions scolaires.
