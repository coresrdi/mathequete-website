Tableau de bord prof — Windows

Bêta

Application Windows native (Tauri + WebView2). Permet de gérer vos classes, importer vos élèves, visualiser leurs progrès, créer des îles bonus personnalisées.

Gratuit, sans achat dans l'application. Toutes les fonctionnalités payantes nécessitent une licence d'élève achetée séparément.

Compatible Windows 10 / 11 (64 bits). Prérequis : WebView2 Runtime (généralement déjà installé).

En savoir plus

Le lien de téléchargement direct est disponible sur la page « En savoir plus ».

Versions macOS et Linux du tableau de bord à l'étude.

Compatibilité

Oui. Vos codes d'activation Mathéquête sont multiplateformes. Une fois iOS et Windows disponibles, vous pourrez activer votre licence sur n'importe quelle plateforme avec le même code reçu après votre achat initial.

Une licence individuelle = 1 appareil à la fois. Vous pouvez transférer votre licence vers un nouvel appareil à tout moment. Pour les licences permanentes, un seul transfert est autorisé dans les 12 premiers mois suivant l'achat. Les licences annuelles sont transférables sans restriction de temps.
