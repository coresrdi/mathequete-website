Tableau de bord prof — Windows

Bêta

Application Windows native (Tauri + WebView2). Permet de gérer vos classes, importer vos élèves, visualiser leurs progrès, créer des îles bonus personnalisées.

Gratuit, sans achat dans l'application. Toutes les fonctionnalités payantes nécessitent une licence d'élève achetée séparément.

Compatible Windows 10 / 11 (64 bits). Prérequis : WebView2 Runtime (généralement déjà installé).

En savoir plus

Le lien de téléchargement direct est disponible sur la page « En savoir plus ».
