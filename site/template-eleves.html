Comment l'utiliser

1

Télécharge le fichier

Clique sur le bouton ci-dessus. Le fichier s'enregistre dans tes téléchargements.

2

Ouvre dans Excel ou LibreOffice

Le fichier comporte 3 onglets : Instructions, Eleves, et Schema. Va dans l'onglet Eleves.

3

Remplis une ligne par élève

Le prénom est obligatoire. Nom, niveau et code court sont facultatifs. Tu peux mettre jusqu'à 200 élèves par fichier.

4

Importe dans l'app pour enseignants

Ouvre l'application Mathéquête pour enseignants, choisis « Importer ma liste », puis sélectionne le fichier que tu viens de remplir.

Les colonnes du tableau

Colonne Requise Description
Prénom ✅ Oui Lettres accentuées acceptées. Minimum 2 caractères.
Nom Non Aide à identifier les élèves qui ont le même prénom.
Niveau Non Liste déroulante : maternelle, 1re à 6e année.
Code court Non 1 à 4 caractères pour distinguer 2 élèves homonymes (ex : « T » et « B »).

Tes données restent chez toi

Quand tu importes ta liste dans l'application Mathéquête pour enseignants, les prénoms et noms de tes élèves sont chiffrés sur ton appareil avant d'être envoyés à notre serveur. Notre serveur ne reçoit jamais ces informations en clair.

Seuls des codes anonymes (empreintes mathématiques) circulent pour permettre le rapprochement automatique entre tes élèves et les codes QR qu'ils activeront sur leur appareil. Cela respecte les exigences de la Loi 25 du Québec (§38, minimisation des données).

Questions fréquentes

Je n'ai pas Excel. Puis-je quand même utiliser ce template ?

Oui. LibreOffice Calc (gratuit, Windows/Mac/Linux) ouvre et enregistre les fichiers .xlsx sans problème. Google Sheets fonctionne aussi : importe le fichier dans Drive, modifie-le, puis télécharge-le au format .xlsx.

Je veux modifier ma liste après l'avoir importée. Comment faire ?

Réouvre ton fichier, modifie-le, et importe-le à nouveau dans l'app. Le nouvel import remplace complètement l'ancien. Les codes QR déjà attribués à des élèves restent associés grâce au rapprochement automatique.

Que se passe-t-il si deux élèves ont le même prénom ?

Utilise la colonne Code court pour les distinguer (ex : « T » pour Tremblay, « B » pour Bouchard, ou « 2A » pour une classe particulière). Quand l'élève saisit son prénom dans le jeu, il indique aussi son code court — le rapprochement est automatique.

Le template évoluera-t-il ?

Si une future version ajoute des colonnes ou change la structure, l'application te préviendra clairement et te guidera. La version actuelle (eleves-v1) restera supportée. La version est indiquée dans l'onglet Schema du fichier.
