Centre d'aide

Une question ? Consultez les rubriques ci-dessous ou écrivez-nous directement.

🔑 Activer mon code QR

Ouvrez le jeu → Réglages → Activer un code de licence → saisissez votre code XXXX-XXXX-XXXX ou scannez le QR. Une connexion Internet est requise pour l'activation initiale.

📱 Changer d'appareil

Votre licence est transférable dans une fenêtre de 1 an. Consultez la page Transférer ma licence pour la procédure complète.

📶 Jeu hors-ligne

Après l'activation initiale, le jeu fonctionne sans Internet. Une vérification est requise environ tous les 30 jours. Après 40 jours sans connexion, le jeu revient en mode gratuit jusqu'à la prochaine connexion.

🏫 Licences école

Pour les établissements, consultez la page Licences école. Pour un devis ou une aide à la distribution, écrivez à coresrdi@outlook.com.

🪟 Windows PC (Microsoft Store)

Le jeu est disponible sur le Microsoft Store. Recherchez MathéQuête. L'achat de licence se fait sur ce site — utilisez ensuite le bouton dans Réglages pour vous rediriger.
